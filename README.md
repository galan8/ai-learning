# AI Learning System

My long term, living repository documenting my learning journey in AI and AI Security. Everything I learn, understand, read, try and build lives here, organised so the repository grows indefinitely without restructuring.

## Structure

```
ai-learning/
├── courses/       One self contained folder per course: its notes and its exercises
├── concepts/      My own words: one file per concept, synthesised across all sources
├── experiments/   Small implementations, tests and paper reproductions
├── projects/      Complete self contained builds
├── papers/        Reading list and one summary note per paper
└── resources/     Curated links, tools, books and references
```

## The routing rule

Every new piece of material answers one question: what did I do with it?

| Verb | Destination |
| ---- | ----------- |
| I learned it from a course | `courses/<course>/notes/` and its labs in `courses/<course>/exercises/` |
| I understood it and can explain it | `concepts/<concept>.md` |
| I ran it as a small try or test | `experiments/` |
| I built it as a finished thing | `projects/<name>/` |
| I read it | `papers/` |
| I might use it later | `resources/` |

No source is the organising principle: a course is one input among many, and understanding accumulates in `concepts/` regardless of where it came from.
