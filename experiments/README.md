# Experiments

Small implementations, tests, benchmarks and paper reproductions. Experiments are things I try; `projects/` is for things I build and finish.

Each experiment gets a folder or file named `YYYY-MM-<short-name>`, containing:

1. Question: what I wanted to find out
2. Setup: code, data, environment
3. Result: what happened
4. Conclusion: what I learned, and whether it should graduate into a project
