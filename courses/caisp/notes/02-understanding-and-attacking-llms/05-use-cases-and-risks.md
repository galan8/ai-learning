# LLM Use Cases and Risks

## Importance and impact

Use cases at a high level:

1. Enhanced communication platforms
2. Software development acceleration: real time code completion, troubleshooting, refactoring
3. Advanced data intelligence: querying and summarising large volumes of unstructured data
4. Global communication solutions: translation and localisation
5. Content strategy and creation: drafting content, summarising meetings from transcripts

## Risks

Newer technologies need time to mature.

1. **Bias and fairness**: models inherit the biases present in their training data, which raises ethical concerns. If the data is tainted, the responses are tainted.
2. **Security**: models can be misused to generate misleading or harmful content, including malware and phishing material.
3. **Privacy**: sensitive data can leak through an LLM, especially when it is connected to private data sources. Leakage can come from the training data, from data pasted into prompts, or from retrieval sources the model can reach.

## Use cases in detail

### Text generation

Creating marketing content, chatbots, coding assistants, and high quality outputs such as articles, summaries and captions.

1. Content creation for blogs, social media and other platforms
2. Dialogue generation for chatbots, virtual assistants and other conversational agents
3. Storytelling: developing stories from a particular theme or prompt
4. Augmentation: expanding existing content to make it richer and more detailed

### Text understanding

Interpreting, analysing and deriving meaning from text. Models such as GPT and BERT perform tasks including:

1. Summarisation: condensing large pieces of text
2. Sentiment analysis: determining emotional tone (positive, negative, neutral)
3. Information extraction from large volumes of text (for example Donovan from Scale AI)

### Conversational AI

Engaging in human like dialogue, interacting with users through text or speech in a way that resembles human conversation.

### Grouped by domain

1. **Text generation and writing**: content generation, email drafting, report writing, story generation
2. **Language tasks**: translation, summarisation, grammar correction, paraphrasing
3. **Programming**: code generation, code explanation, code optimisation, debugging
4. **Analytics and understanding**: sentiment analysis, topic classification, information extraction, research assistance
5. **Creative and educational**: course creation, creative writing, brainstorming, quiz generation
6. **Legal and compliance**: contract analysis, legal research, document review, case summarisation

## Open question from the course

What can LLMs not help with yet? Candidates include tasks needing guaranteed factual accuracy, real time or private knowledge they cannot reach, genuine causal reasoning, accountability for decisions, and anything where a confident wrong answer is more dangerous than no answer.
