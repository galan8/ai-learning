# CAISP Exercises

Labs and exercises from the CAISP course. One file or folder per exercise, named `<chapter>-<short-name>`, e.g. `02-prompt-injection-lab.md`.

Suggested template for each exercise:

1. Objective: what the exercise asks for
2. Environment and tools used
3. Steps: commands, code, screenshots
4. Result and output
5. Lessons learned
