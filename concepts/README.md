# Concepts

My understanding in my own words: one file per concept, synthesised across every source that taught it to me. This folder is organised by concept, not by course, so knowledge from CAISP, papers, Hugging Face and anywhere else merges into a single explanation.

Naming: `<concept>.md` in lowercase with hyphens, e.g. `prompt-injection.md`, `embeddings.md`, `transformers.md`.

Suggested template for each concept:

1. The concept in one paragraph, as I would explain it to someone else
2. Why it matters (especially for AI security)
3. How it works in more detail
4. Sources: links to the notes, papers and exercises where I learned it
